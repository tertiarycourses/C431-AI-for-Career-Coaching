## About the course

Develop practical AI-assisted career coaching skills through four concept-led topics and eight connected labs. Work with a fictional career transition to draft coaching questions, map skills, compare options, prepare applications, rehearse interviews and implement a reviewed action plan. Human coaches and clients retain control of decisions.

## Learning outcomes

- LO1: Conduct a consent-based career intake and use AI to draft neutral coaching questions.
- LO2: Map documented skills to role requirements and compare feasible career options.
- LO3: Create truthful application materials and rehearse evidence-based interview responses.
- LO4: Design a client-owned career action plan and review progress using appropriate indicators.

## Topics covered

- Career Development Principles
- Assess Employee Competencies
- Career Management
- Support Career Plan Implementation
